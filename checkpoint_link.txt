包含两个 tar.gz：
- `octo_head_only_step750.tar.gz` (~300 MB)
- `octo_full_step750.tar.gz` (~300 MB)

## Contents

Each tar.gz extracts to `octo_{head_only|full}_step750/` containing:

```
├── 750/                       # orbax checkpoint
├── config.json                # model arch
├── dataset_statistics.json    # action normalization stats (required for eval)
├── example_batch.msgpack      # dummy input for init
└── finetune_config.json       # training hyperparams snapshot
```

## Base model

Final checkpoints are fine-tuned on top of `rail-berkeley/octo-small-1.5` step 300000. The base model's own config and example batch are unchanged; only `dataset_statistics.json` is from the fine-tuned run and must be used at eval time.

## Load

```python
import os
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"   # T5 tokenizer

from octo.model.octo_model import OctoModel
model = OctoModel.load_pretrained("/path/to/octo_head_only_step750", step=750)
```
